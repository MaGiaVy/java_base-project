Cổng Dịch Vụ Mạng Đa Nền Tảng (Server 2)

Bạn đang kết nối thành công tới Server 2 (Cổng 8081). Theo sơ đồ trên bảng của Thầy, đây là máy chủ thứ hai hoạt động độc lập, quản lý và phục vụ nhóm tài nguyên P3.HTM và P4.HTM.

THÔNG SỐ MÁY CHỦ TRẠNG THÁI VẬN HÀNH
Cổng lắng nghe (Port): TCP Port 8081 (Phân tách hoàn toàn với Port 8080)
Thư mục tài nguyên: webroot2/ (Chỉ chứa P3.HTM và P4.HTM)
Dịch vụ hỗ trợ: Phục vụ Static Web, API thời gian (/api/time) & API Tin nhắn (/api/message)

ĐIỀU HƯỚNG LIÊN MÁY CHỦ:

→ Chuyển Sang P4.HTM (Cùng Server 2)
⇐ Quay Về P1.HTM (Server 1: 8080)
