📖 GIẢI THÍCH KIẾN TRÚC MÔN HỌC & YÊU CẦU CỦA THẦY (CHƯƠNG 12) Chuẩn RFC 2616 / HTTP 1.1

Câu hỏi của Thầy: "Làm giống Chrome, kiểu có Client với Server, Server sẽ lấy file HTML sau đó cho các Client có thể mở được. Bản chất hoạt động thế nào?"

  • Phía Server: Lắng nghe tại cổng TCP (80 đối với IIS, 8080 đối với Java Server). Khi nhận HTTP Request dạng văn bản (ví dụ GET /P1.html HTTP/1.1), Server tìm file trên ổ đĩa, bọc lại thành gói tin HTTP Response kèm mã trạng thái 200 OK, header Content-Type: text/html; charset=UTF-8 rồi gửi qua Socket.
  • Phía Client: Trình duyệt (Chrome hoặc MiniBrowser.java) nhận luồng byte, giải mã bảng mã ký tự, và dùng bộ phân tích cú pháp HTML (DOM Parser) để vẽ nội dung, tạo liên kết (Hyperlinks) cho người dùng duyệt trang.

🛠️ HƯỚNG DẪN THAO TÁC TRỰC TIẾP TRÊN IIS MANAGER CHO THẦY XEM
  1. Mở IIS Manager: Bấm Windows + R, gõ inetmgr hoặc nhấp đúp file open_iis_manager.bat.
  2. Duyệt file qua Content View: Chọn Sites > Default Web Site > Chuyển sang tab Content View ở dưới cùng màn hình.
  3. Bấm Browse mở trang web: Nhấp chuột phải vào file index.html (hoặc P1.html) > chọn Browse. Trình duyệt Chrome sẽ tự động mở trang web này từ IIS cổng 80!
  4. Kiểm tra Thư mục vật lý & Cổng: Nhấp chuột phải Default Web Site > chọn Basic Settings để thấy Physical Path: C:\inetpub\wwwroot và chọn Bindings để thấy Port 80.
