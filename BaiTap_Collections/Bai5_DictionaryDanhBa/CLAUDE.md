# Bài 5: Quản Lý Danh Bạ (Dictionary / Map)

## Mô tả yêu cầu

Sử dụng `Map<String, String>` (tương đương `Dictionary<string, string>`):

- Khóa (Key): Số điện thoại.
- Giá trị (Value): Họ tên.

### Các chức năng:

1. Thêm liên hệ mới.
2. Tìm kiếm theo số điện thoại (Khóa).
3. Cập nhật tên theo số điện thoại.
4. Xóa liên hệ.
5. Hiển thị toàn bộ danh bạ.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 QuanLyDanhBa.java
java QuanLyDanhBa
```
