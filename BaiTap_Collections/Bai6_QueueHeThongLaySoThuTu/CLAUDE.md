# Bài 6: Mô Phỏng Hệ Thống Lấy Số Thứ Tự (Queue<T>)

## Mô tả yêu cầu

Sử dụng `Queue<String>` (hàng đợi FIFO).

### Các chức năng:

1. Thêm khách hàng vào hàng đợi (phát số thứ tự).
2. Phục vụ khách hàng đầu tiên trong hàng đợi.
3. Hiển thị danh sách khách hàng đang chờ.
4. Hiển thị số lượng khách hàng còn lại.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 HeThongLaySo.java
java HeThongLaySo
```
