# Bài 8: Chương Trình Quản Lý Sinh Viên (File I/O)

## Mô tả yêu cầu

Xây dựng chương trình quản lý sinh viên với các chức năng:

1. Thêm sinh viên.
2. Hiển thị danh sách sinh viên.
3. Tìm kiếm theo mã hoặc họ tên.
4. Cập nhật thông tin sinh viên.
5. Xóa sinh viên.
6. Lưu dữ liệu vào Text File (`SinhVien_Data.txt`).
7. Đọc dữ liệu từ Text File khi khởi động chương trình.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 *.java
java QuanLySinhVien
```
