# Bài 3: Tìm Kiếm Dữ Liệu Từ File

## Mô tả yêu cầu

Tìm kiếm sinh viên từ tập tin văn bản `SinhVien.txt`.

### Yêu cầu:

- Tìm sinh viên theo mã sinh viên.
- Tìm sinh viên theo họ tên (hỗ trợ tìm kiếm gần đúng).
- Hiển thị kết quả tìm kiếm chi tiết.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 TimKiemSinhVien.java
java TimKiemSinhVien
```
