# Bài 1: Ghi Dữ Liệu Vào Tập Tin

## Mô tả yêu cầu

Viết chương trình nhập thông tin sinh viên gồm:

- Mã sinh viên
- Họ tên
- Lớp
- Điểm trung bình

### Yêu cầu:

- Ghi thông tin vào tập tin `SinhVien.txt`.
- Mỗi sinh viên lưu trên một dòng, cách nhau bằng dấu chấm phẩy `;`.
  Ví dụ:
  ```
  SV001;Nguyen Van A;CNTT01;8.50
  SV002;Tran Thi B;CNTT02;7.80
  ```

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 GhiSinhVien.java
java GhiSinhVien
```
