# Bài 1: Xử Lý Lỗi Nhập Dữ Liệu

## Mô tả yêu cầu

Viết chương trình nhập hai số nguyên và thực hiện phép chia.

### Yêu cầu:

- Sử dụng `try-catch` để xử lý:
  - Nhập sai kiểu dữ liệu (`NumberFormatException`).
  - Chia cho 0 (`ArithmeticException`).
- Hiển thị thông báo lỗi phù hợp.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 PhepChia.java
java PhepChia
```
