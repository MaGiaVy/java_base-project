# Bài 3: Sử Dụng Finally

## Mô tả yêu cầu

Viết chương trình đọc dữ liệu từ một tập tin văn bản.

### Yêu cầu:

- Nếu tập tin không tồn tại, thông báo lỗi (`FileNotFoundException`).
- Luôn giải phóng / đóng tập tin trong khối `finally`.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 DocFile.java
java DocFile
```
