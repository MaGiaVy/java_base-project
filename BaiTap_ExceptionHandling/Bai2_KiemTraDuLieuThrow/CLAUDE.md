# Bài 2: Kiểm Tra Dữ Liệu Bằng Throw

## Mô tả yêu cầu

Viết chương trình nhập thông tin sinh viên:

- Mã sinh viên
- Họ tên
- Điểm trung bình

### Yêu cầu:

- Nếu điểm < 0 hoặc > 10 thì phát sinh ngoại lệ bằng lệnh `throw`.
- Hiển thị thông báo lỗi và yêu cầu nhập lại cho đến khi hợp lệ.

## Cách biên dịch và chạy

```bash
javac -encoding UTF-8 KiemTraSinhVien.java
java KiemTraSinhVien
```
